# Logonomic OpenRig add-on

Provider repository for [OpenRig](https://github.com/mvschwarz/openrig), the
`@openrig/cli` package whose command is `rig`.

The integration contract is maintained in Logonomic's
[OpenRig hook support plan](https://github.com/Varinomics/logonomic/blob/master/docs/openrig_hook_support_plan.md).
A dashboard is a presentation of independent native seats; it is not itself a
native model conversation. Hook capabilities must be declared only when the
host can bind each seat to its own native provider, package generation and
instruction authority.

## Support matrix

| Boundary | Required contract |
| --- | --- |
| Saved launcher | Preserve the exact shell, arguments, profile, directory and approval policy. |
| Native seat | Independent authority, lifecycle, instruction consumption and callbacks. |
| Existing seat enrollment | Supported targeted wrapper update for the next user-directed launch, preserving rig, seat and history. |
| Wrapper lifetime | Persisted configuration survives owner exit and package-generation cleanup. |
| Windows | Linux-native assets in WSL2 with a validated scoped bridge to the Windows host. |

The package capability declarations are the authority for executable support.
The repository's existence does not advertise native hook parity or activate a
provider in the official package roster.
